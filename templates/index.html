Backend Architecture

This UI is powered by a Python Flask server and SQLite DB using RESTful APIs:

  • GET /api/students - Fetch student list
  • POST /api/students - Add new student
  • POST /api/attendance - Save daily logs
  • GET /api/reports - Real-time percentage & shortage analysis
